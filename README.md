# BMI & Healthy Weight Range Health Tool
Calculate BMI and healthy weight range with a visual color-scale gauge.
## Features
- Metric (cm/kg) and Imperial (ft-in/lbs) unit toggle
- Real-time BMI calculation with category label (underweight / normal / overweight / obese)
- Healthy weight range displayed for entered height
- Animated gauge needle on a color-coded scale
- Disclaimer banner for informational use only
## Tech
Static SPA · Tailwind CDN · localStorage
